REXTOの「出席簿」とは

REXTOに来た日を記録する、スマホのスタンプカードです。来店は「出席」。出席を重ねると称号が上がり、学期ごとの特典やランキングもあります。参加は無料です。

使い方

  1. LINEのメニューから「出席簿」を開きます
  2. はじめての方は、ランキングに表示するお名前を登録します（最初の1回だけ）
  3. 校舎に着いたら「出席する」を押します
  4. 出席簿にハンコが押されます（磐＝磐田校、原＝原島校）

出席のルール

  • 磐田校・原島校のどちらでも出席できます。出席は1日1回まで（両校合わせて1回）です
  • 校舎にいるかどうかは、押したときのスマホの位置で確認します。位置は確認にだけ使い、保存しません
  • うまく押せないときは、受付のQRコードを読み込んでください
  • 押し忘れた日は出席になりません

学期と特典

1学期＝4〜7月、2学期＝8〜11月、3学期＝12〜3月。学期ごとの出席日数で特典があります。達成すると「たいへんよくできました」のハンコが押されます。受付で商品を受け取るときに、ご自身で「商品と交換する」を押してください。

    称号

    年間（4月〜3月）の出席日数で昇進します。年度末の年間1位の方が「生徒会長」です。毎年4月に新学年としてリセットされます。

      称号はリセットされても、記録は残ります。生徒会長になった回数だけ名前の横に👑、副会長まで昇進した回数だけ⭐が付きます。これまでの年度の成績は「わたしの出席簿」の「これまでの記録」で見られます。

      ランキング

      出席日数が多い方が上位です。出席日数が同じ場合は、在籍年数が長い方が上位です（「在籍3年目」なら3年として、年の単位で比べます）。それも同じ場合は、最後の出席日が新しい方が上位です（それも同じなら、その前の出席日で比べます）。出席は押した瞬間に反映されます。

      よくある質問

      名前は変えられますか？
      出席簿の名前の横にある「名前を変える」から変更できます。これまでの出席はそのまま残ります。
      位置情報が取れないと出ます
      iPhoneは「設定 → LINE → 位置情報 → このAppの使用中のみ許可」、Androidは「設定 → アプリ → LINE → 権限 → 位置情報 → 許可」にしてください。それでもだめなときは受付のQRコードをどうぞ。
      機種変更しても出席は残りますか？
      はい。同じLINEアカウントを引き継げば、そのまま残ります。
      毎日来てもいいですか？
      もちろんです。連続出席が続いてもブラック校ではありません。
